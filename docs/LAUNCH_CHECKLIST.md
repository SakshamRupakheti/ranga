# Public launch gate

**Not ready for public launch. This is a local development preview.**

An item is complete only when supported by test results or a verified service response. Local editor checks are tracked in VERIFICATION.md; they do not imply that a cloud service is configured.

- [ ] Private GitHub repository connected and branches pushed.
- [ ] Hosted TypeScript, lint, unit, browser, and build checks pass.
- [ ] Main branch protection and dependency monitoring active.
- [ ] Private preview deployment verified before production exposure.
- [ ] Product authentication/session management implemented and tested.
- [ ] Cross-user access isolation tested on every server resource.
- [ ] Secrets secured; connected-service tokens encrypted; least-privilege scopes reviewed.
- [ ] Cloud save/load and upload authorization tested with failure recovery.
- [ ] Main editor critical paths pass in supported browsers and real mobile devices.
- [ ] Export compatibility reviewed against intended destinations.
- [ ] Advertised OAuth integrations configured and tested with real authorized accounts.
- [ ] AI structured commands validated; prompt injection and budget controls tested.
- [ ] Accessibility review completed, including contrast, keyboard, screen reader, and touch.
- [ ] Backups/restoration, retention, disconnect, and deletion flows tested.
- [ ] Accurate privacy policy and terms written and reviewed.
- [ ] Support channel, error monitoring, and incident handling in place.
- [ ] Custom domain and HTTPS verified.
- [ ] Ranga logo and favicon created using the editor and installed.
- [ ] No fake claims, testimonials, metrics, nonfunctional advertised controls, or unwanted branding.
- [ ] Outstanding development dependency advisories reviewed and accepted or remediated.

No production deployment, custom domain, paid subscription, API key, or OAuth app was created during the local milestone.
